# myLinear P0产品模块设计

> **阶段范围**（对应 README 路线图 P0）：workspace / member / project / task 的 CRUD + 任务列表（按状态分组 + 两层子任务树）。
> **上游依据**：[DATABASE_DESIGN.md](../../DATABASE_DESIGN.md)（v1.3 schema 定稿）、[DESIGN-linear.app.md](../../DESIGN-linear.app.md)（视觉 token 基准）。
> **本阶段不含**：Label 标签体系（P1）、视图页（P1 内置 / P2 自定义）、列表行内编辑（P3）。涉及标签/视图的 UI 位在本阶段一律省略或置空。
> **文档性质**：阶段快照，定稿后不再修改；后续阶段另起 P1.md / P2.md。README.md 为活文档，随开发阶段持续更新。

## 0. 全局布局

左右两栏结构（对齐 Linear）：

```
┌─────────────────────┬──────────────────────────────────┐
│  左侧 Sidebar        │  右侧内容区                        │
│                      │                                  │
│  + 新建 workspace    │  随左侧导航切换：                   │
│  ─────────────      │  workspace 编辑页 / 项目列表 /       │
│  ▸ workspace A       │  任务列表                          │
│  ▸ workspace B       │                                  │
└─────────────────────┴──────────────────────────────────┘
```

- 初始状态：workspace 列表为空，右侧为空状态引导页，引导创建第一个 workspace
- 点击 "+"：右侧变为 workspace 创建页
- 每个 workspace 是**可展开的导航树节点**，展开后包含子项：
  - **Home**：workspace 概览（名称、描述编辑）+ 成员管理（P1 加入标签管理区）
  - **Projects**：该 workspace 下的项目列表
  - **Tasks**：该 workspace 下的全部任务列表
  - **Views**：P1 引入（内置固定视图），P0 不展示该入口
- 整体暗色，遵循 DESIGN-linear.app.md 设计 token

## 1. Workspace 模块

**职责**：顶层容器，承载项目与成员。

- 创建 workspace：name（必填）、description（可选）
- **Home 页**（参考 Linear 的 Team Home，做简化）：
  - Overview 区：workspace 名称、description 的查看与编辑
  - Members 区：成员管理（见下）
  - Linear 的 Documents / Team resources / Connect channel / Team settings 等全部裁剪
- **成员管理**：
  - 与 Linear 的邀请制不同，myLinear 为**人工添加**：直接手动录入成员信息
  - 成员 = "责任人名片"：name（**必填**）、email（可选，不做格式与唯一性限制）、avatar_color（可选）
  - 列表展示参考 Linear Members 页：Name / Email 两列的表格 + "+ Add a member"；**无 Role 列**（MVP 无角色体系）
  - 成员的增删改；删除成员时其名下任务/项目自动变为未指派（数据库 SET NULL 已保证）

## 2. Project 模块

**职责**：任务的归属容器（任务也可不归属任何项目），自身有状态、优先级。

- **项目列表页**：
  - 表格列：名称、status、priority、lead、start_date → target_date、任务数
  - 顶部 "+ New project" 打开**新建弹窗**（非页面跳转）
  - 支持按 name / created_at / priority / status 排序
  - 裁剪：Linear 的 Health 列；**列表不展示标签**（标签 P1，统一在详情页管理）
- **新建项目弹窗**（参考 Linear New project 弹窗）：
  - 字段：name（必填）、description
  - 属性：status（**默认选中 backlog**）、priority（**默认 0 No priority**）、lead、members、start / target 日期
  - 裁剪：Dependencies、Milestones、labels（P1）
- **项目详情页**（点击列表行进入）：
  - 属性面板：编辑 status / priority / lead / members / start→target 日期（labels 于 P1 加入）
  - 编辑名称、description
  - **项目任务列表**：展示该项目下所有任务（复用任务列表组件：按状态分组、树形子任务，可直接新建任务并自动归属本项目）
  - 裁剪：Activity、Resources、Write project update、Milestones、Progress 图表等
- 删除：软删除。**其下任务不级联删除**——应用层将这些任务的 project_id 置 NULL，任务保留为无项目任务（"绑定关系消散，业务本体保留"）
- 规则提醒（后端保证）：lead 与 members 互斥；无 lead 是合法状态（No lead）

## 3. Task 模块

**职责**：系统的核心实体。**任务可不归属任何项目**（对齐 Linear：issue 是独立实体，project 是可选归属），支持子任务树。

- **任务列表页**：
  - 行展示：status 图标、title、所属 project chip、assignee、due_date（label chip 于 P1 加入）
  - 默认按 status 分组展示（分组可折叠，对齐 Linear 的 Todo 4 / Done 13 样式）
  - 子任务以**树形缩进**嵌在父任务下方，可展开/折叠；MVP 先展示两层（任务 → 子任务），数据模型不限深度
  - 顶部固定筛选 tab：**Active / Backlog / All**（Active = todo + in_progress；Backlog = backlog；All = 全部）；默认选中 All（侧栏 Tasks 入口、任务删除后回列表均同）
  - 新建入口：每个 status 分组行尾的 "+" 打开**新建弹窗**：title（必填）、status（默认选中点击的那个分组）、priority（默认 0）、assignee / due_date / 所属 project（可选；labels 于 P1 加入）
  - 列表行只读，不做行内编辑（P3）
  - 裁剪：Linear 右上角的丰富展示控制（自定义筛选器、List/Board 切换、分组/排序/显示属性开关、右侧统计面板）——归入 P2 视图体系
- **任务详情页**（点击列表行进入）：
  - 编辑 title、description
  - 子任务详情页标题下展示 "Sub-issue of [status] 父任务名 x/y" 行（对齐 Linear；x/y = 父任务后代完成统计，点击父任务名跳父任务详情；数据随 GetTask 的 parent 字段返回，无额外请求）
  - 右侧属性面板：status / priority / assignee / due_date 可修改（labels 于 P1 加入）；所属 project 可修改或置空（修改时应用层同步其子任务的 project 归属）
  - **子任务区**：展示子任务树（带完成进度 x/y 徽标）；"+ 添加子任务" 行内快速创建（title + 可选属性，Cancel/Create）；子任务可再点进去继续添加下一层
  - 裁剪：Activity 动态、评论、附件、订阅、任务编号（GHO-13）、工时估算
- 删除：软删除（级联软删整棵子树）
- 规则提醒（后端保证，对应 api.md §3 业务规则）：
  - 任务 assignee 只需是本 workspace 成员（或留空），与项目 lead/members 解绑（2026-09 起对齐 Linear：项目成员仅为干系人概念，不构成指派边界）
  - 子任务与父任务同 workspace 且 project 一致（父任务无项目则子任务也无项目）

## 4. 本阶段路由（react-router）

```
/                                   → 空状态引导 / 第一个 workspace 的 Home
/w/:workspaceId/home                → workspace 编辑 + 成员管理
/w/:workspaceId/projects            → 项目列表
/w/:workspaceId/projects/:projectId → 项目详情（属性 + 该项目任务）
/w/:workspaceId/tasks              → 任务列表（分组 + 树形子任务）
/w/:workspaceId/tasks/:taskId       → 任务详情（子任务树）
```

（P1 增加 `/w/:workspaceId/views` 与 `/w/:workspaceId/views/:viewId`。）
